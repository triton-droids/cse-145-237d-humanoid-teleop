01 — Abstract

What we built

We built a humanoid teleoperation pipeline that lets a humanoid robot imitate lower-body human motion. Our system combines wearable IMU nodes, a depth-camera perception baseline, calibration and inverse kinematics, retargeting to the Triton humanoid model, and reinforcement-learning simulation in Isaac Lab.

02 — Pipeline

From human motion to robot motion

What we built this quarter — each stage links to the code on GitHub.

01

Wearable IMUs

BNO085 quaternion streams from ESP32-S3 nodes over UDP. Packet parsing, latest-packet buffering, filtering, smoothing, and neutral calibration on the Jetson.

wearable_imu/ →
02

Depth-Camera Baseline

Intel RealSense D435 + MediaPipe estimates depth-backed pose landmarks as a parallel perception baseline alongside the wearable rig.

perception/depth_camera/ →
03

IK & Calibration

Lower-body orientation IK from quaternion streams, validated with a MuJoCo synthetic test harness before touching the real robot.

04

Retargeting

Map human joint trajectories onto the Triton humanoid via the ch_robot joint-order contract and the Holosoma converter patch.
